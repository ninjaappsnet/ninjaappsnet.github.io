title: Tutorials
heading: Learn FlectoBI by building
description: Step-by-step tutorials for FlectoBI on Mac: shape real files into a Flow you can run again, then turn it into a Report that refreshes with it.
---

Each tutorial starts from data you might have, such as a month of sales exports, and ends with something that works: a Flow you can run again, or a Report you can hand over. Most use the Sales Sample Workbook, which opens from FlectoBI’s Help menu, so you can follow along before you bring your own files.
