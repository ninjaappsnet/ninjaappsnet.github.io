Most of Diagrove can be used from the keyboard. This page lists the Mac’s shortcuts menu by menu, then the keys the canvas takes and the ones to hold while you drag, then what changes on iPad with a hardware keyboard. The last part says how Diagrove works with VoiceOver, larger text, Reduce Motion, Reduce Transparency and Increase Contrast.

## Mac menu shortcuts

The menus name the shortcuts too: each one is shown beside its item.

### File

| Shortcut | Command |
|---|---|
| Command‑N | New diagram |
| Control‑Command‑N | New isometric diagram |
| Shift‑Command‑N | New from template… |
| Option‑Shift‑Command‑N | Describe a diagram… |
| Shift‑Command‑E | Export… |
| Shift‑Command‑P | Page Setup… |
| Command‑P | Print… |

Open… (Command-O), Close (Command-W) and Save (Command-S) keep the Mac’s usual keys. Import…, Save as template…, Send to Dayfolio… and New diagram from sketch or photo… have no shortcut.

### Edit

| Shortcut | Command |
|---|---|
| Shift‑Command‑A | Deselect All |
| Option‑Shift‑Command‑C | Copy as Diagrove text |
| Command‑D | Duplicate |

Undo (Command-Z), Redo (Shift-Command-Z), Cut, Copy, Paste and Select All (Command-X, Command-C, Command-V and Command-A) work as in every Mac app. **Copy as Diagrove text** copies the selection, or the whole canvas when nothing is selected. See [Import and export](../import-and-export/).

### View

| Shortcut | Command |
|---|---|
| Control‑Command‑S | Hide Sidebar, or Show Sidebar |
| Control‑Command‑I | Show Inspector, or Hide Inspector |
| Command‑+ | Zoom in |
| Command‑- | Zoom out |
| Command‑0 | Actual size |
| Option‑Command‑0 | Zoom to fit |
| Command‑R | Show rulers, or Hide rulers |
| Option‑Command‑P | Play, or Stop playing |

**Guides** and **Preview as embed** have no shortcut. On an isometric canvas, **Show rulers** is dimmed and **Guides** isn’t shown. See [Drawing](../drawing/) and [Play mode and actions](../play-mode-and-actions/).

### Insert

| Shortcut | Command |
|---|---|
| Shift‑Command‑I | Picture… |
| Option‑Shift‑Command‑I | Drawing… |

**Diagram from sketch or photo…** has no shortcut.

### Arrange

| Shortcut | Command |
|---|---|
| Shift‑Command‑G | Group |
| Shift‑Command‑U | Ungroup |
| Shift‑Command‑F | Bring to front |
| Option‑Shift‑Command‑F | Bring forward |
| Option‑Shift‑Command‑B | Send backward |
| Shift‑Command‑B | Send to back |
| Shift‑Command‑L | Auto-arrange › Flow, top to bottom |

**Flip horizontal** and **Flip vertical** are in this menu without a shortcut, because their keys belong to the canvas: with a graphic selected, Shift-H and Shift-V flip it. Align, Distribute, the other Auto-arrange layouts, the masks and Plane (on an isometric canvas) have no shortcut.

### Canvas

| Shortcut | Command |
|---|---|
| Option‑Command‑N | New canvas |
| Option‑Command‑L | New layer |

### Window and Help

| Shortcut | Command |
|---|---|
| Shift‑Command‑1 | Window › Welcome to Diagrove |
| Command‑? | Help › Diagrove guide |

Minimise (Command-M), Settings… (Command-,), Hide Diagrove (Command-H) and Quit Diagrove (Command-Q) are the Mac’s own.

## On the canvas

These work while the canvas has the keyboard, not while you type into a shape or a field.

### Tools

| Key | Tool |
|---|---|
| V | Select |
| R | Rectangle |
| O | Ellipse |
| D | Diamond |
| L | Line |
| T | Text |

A tool’s tooltip names its key, such as “Rectangle — R”. A, S, E and C choose Select, Rectangle, Ellipse and Line too, as in OmniGraffle. Rounded rectangle, More shapes and Table have no key. Control-click the Line tool to choose how new lines are routed.

### The selection

| Key | Action |
|---|---|
| Arrow keys | Nudge the selection 1 point |
| Shift‑arrow keys | Nudge it 10 points |
| Delete | Delete the selection, or the gradient stop chosen in the inspector |
| Return | Edit the selected graphic’s words |
| Shift‑H | Flip the selection horizontally |
| Shift‑V | Flip it vertically. With nothing selected, Shift-V chooses Select |
| 1 to 9 | Set the selection’s opacity, from 10% to 90% |
| 0 | Set its opacity to 100% |
| Esc | Step back, one thing at a time |

Esc steps back from the last thing you started: a change from the prompt bar waiting on the canvas, Play mode, a drag, a drawing tool, a group you entered, and then the selection.

### Typing

| Key | Action |
|---|---|
| Esc | Stop typing and keep the words |
| Tab | In a table, go to the next cell. In the last cell, add a row |
| Shift‑Tab | In a table, go to the previous cell |

### Play mode

| Key | Action |
|---|---|
| Left Arrow | Go back to the canvas you came from |
| Esc | Stop playing |

## Keys to hold while you drag

| Hold | While you | It |
|---|---|---|
| Shift | Move graphics | Keeps the move horizontal or vertical |
| Shift | Resize | Keeps the proportions |
| Shift | Draw a shape | Makes it a square or a circle |
| Shift | Rotate | Turns in steps of 15 degrees |
| Shift | Click a graphic | Adds it to the selection, or takes it out |
| Shift | Drag across empty canvas | Adds what you surround to the selection |
| Command | Move, resize, draw a shape, place a line’s end or drag a table’s border | Turns off snapping to the grid, guides and other graphics |
| Option | Drag a graphic on an isometric canvas | Raises or lowers it |

Resizing one graphic snaps its width or height to a neighbour’s, unless you hold Shift or Command. See [Drawing](../drawing/) and [Isometric canvases](../isometric-canvases/).

## The prompt bar, sheets and panes

### The prompt bar

| Key | Action |
|---|---|
| Return | Draw what you typed or work out the change, or apply the change on show |
| Command‑Return | The same, wherever the keyboard is in the window |
| Esc | Stop the work, discard the change on show, or close the prompt bar guide |

### Sheets

| Key | Action |
|---|---|
| Return | Press the sheet’s main button, such as Export or Create |
| Esc | Cancel, even from a text field |

### The colour popover

| Key | Action |
|---|---|
| Arrow keys | Move between swatches |
| Return or Space | Choose the swatch |
| Tab | Go to the hex field |
| Esc | Close it |

### Number fields

| Key | Action |
|---|---|
| Up Arrow, Down Arrow | Step the value. Hold Shift for steps of ten, Option for tenths |

### The Stencils tab

| Key | Action |
|---|---|
| Command‑[ | Back to the categories |
| Return | In a search, add the best match |
| Arrow keys, then Return | Choose a tile and add it |

### The Outline tab

| Key | Action |
|---|---|
| Up Arrow, Down Arrow | Move between topics |
| Return | Rename the selected topic |

### The Welcome window and the template gallery

| Key | Action |
|---|---|
| Command‑1, Command‑2 | Show Recent or Templates |
| Return | Open the recent document, or create from the template |
| Space | Show the selected template large, or put it away |
| Left Arrow, Right Arrow | In the large preview, the template before or after |
| Shift‑Command‑R | Show the recent document in the Finder |
| Delete | Remove the recent document from the list |
| Command‑F | Search the gallery |
| Any letter | Start a search in the gallery |
| Esc | Close the large preview, end a search, then close the gallery |

See [Getting started](../getting-started/) and [Templates](../templates/).

## iPad with a hardware keyboard

The iPad’s menu bar holds the same commands, built from the same code, with the same keys: Export… (Shift-Command-E), the Edit, Arrange and Canvas shortcuts above, the zoom keys, **View › Show rulers** (Command-R), **View › Play** (Option-Command-P) and **Help › Diagrove guide** (Command-?). Hold Command to see the shortcuts of the app in front.

What differs:

- **Insert** has **Picture from Photos…** (Shift-Command-I), **Picture from Files…** and **Drawing from Files…** (Option-Shift-Command-I).
- **File › Describe a diagram…** (Option-Shift-Command-N) starts a diagram from the start screen. There, choose it from the menu bar, because the Files browser keeps the keys; while the template sheet is open, the shortcut works too. In a document it is off.
- The Mac’s other ways to start (New diagram, New isometric diagram, New from template…), Import…, Page Setup…, Print…, Diagram from sketch or photo…, Command-line tool… and Welcome to Diagrove aren’t in the iPad’s menus. Print… is in the toolbar’s Export menu.

On the canvas, the keys are the Mac’s: the single-key tools, Delete, the arrow keys (with Shift, by 10 points), Return, Shift-H and Shift-V, the digits for opacity, Esc, Tab and Shift-Tab in a table, and the Left Arrow in Play mode. With a trackpad or mouse, Shift and Command do what they do on the Mac while you drag. In the prompt bar, Return sends and Shift-Return starts a new line. In Sketch mode, Esc is **Done**. See [Diagrove on iPad](../ipad/).

## VoiceOver

VoiceOver reads Diagrove on the Mac and on iPad.

- **The canvas** says what’s on it: “4 graphics, 1 selected”. On the Mac it says the canvas’s name first, such as “Sign-up flow, 4 graphics, 1 selected”. Inside a group you entered it says “Inside a group” first, and lists that group’s graphics.
- **Each graphic** says its words, then what it is: “Plan, rectangle”. A line says its label and what it joins, “from Start to Plan”. A table says its size, such as “table, 3 rows, 2 columns”, and the words of its first row; a stencil without words says its stencil’s name. On iPad the graphics come in reading order, top to bottom and left to right, and a thin line can still be found.
- **Changes** are announced on the Mac when graphics come, go or are selected; a drag in progress stays quiet.
- **Play mode** makes each graphic with an action a button, and says what it does, such as “Go to Home screen”. Pressing it runs the action.
- **A selected table** offers Add row and Add column, as its “+” handles do; the handles are buttons too.
- **The tool palette** names each tool and says which one is chosen. The Line tool says how new lines are routed, “New lines: Elbow”, and offers the other routings as actions. **More shapes** says which shape is chosen.
- **The inspector’s** sections are headings, each with an action to show or hide it. A number field says its name, value and unit, and VoiceOver can step it up and down. A colour well says its row and its colour: “Fill, light teal”.
- **The sidebar** reads a layer as “Layer 1, 13 graphics, hidden” and a canvas as “Checkout, Canvas 1 of 2”. A stencil tile says its name and library; pressing it adds the stencil, an action adds it to your favourites, and VoiceOver’s More content rotor reads its preview.
- **The Outline** offers **Rename** and **Add a topic under it** on each topic. On iPad, a topic’s chevron says “Show the topics under” or “Hide the topics under” the topic.
- **Sketch mode** on iPad: the sketch bar is named Sketch, and Pen and Eraser say which one is chosen. The drawing area says how many strokes it holds, such as “Sketch, 3 strokes”, and takes your finger directly, so you can draw with VoiceOver on.
- **Notices** are read out as they arrive. With VoiceOver on, they stay two and a half times as long, up to 25 seconds.

### Colours in words

A colour well, and VoiceOver, call a palette colour by its name, such as “light teal”, and a tone by the palette colour nearest it, so you hear “dark slate” rather than a hex code. A gradient is read as “Gradient from light teal to dark slate”. A colour of your own, off the palette, is read as its hex value.

## Keyboard navigation

To move through the Welcome window, the template gallery and sheets with Tab, turn on **Keyboard navigation** in **System Settings › Keyboard**. Each of the Welcome window’s ways to start then takes Tab and shows a focus ring, and a template grid takes the arrow keys as one control, so a single Tab leaves it. In every sheet, Return presses the main button and Esc cancels.

## Text size on iPad

Diagrove’s own text on iPad follows the size you choose in **Settings › Display & Brightness › Text Size**, and the larger sizes in **Settings › Accessibility**, up to the largest. Above the default size, inspector labels wrap rather than being cut short, and from the largest standard size they move above their controls. At the accessibility sizes the template gallery opens full screen and notices stay two and a half times as long. The words in your diagrams stay the size you drew them. On the Mac, Diagrove keeps its own sizes.

## Reduce Motion

Turn on **Reduce Motion** in the system’s accessibility settings, on the Mac or the iPad. Diagrove then fades things in place instead of moving them:

- Notices fade in where they stay, rather than sliding down. That includes the prompt bar’s progress, such as “Reading your words on this Mac…”, and what it drew.
- The prompt bar’s card for a change on show fades in place, rather than rising from the bar.
- A zoom that would glide, such as Zoom to fit, lands at once.
- Entering a group dims the rest of the canvas at once, rather than fading.
- In Play mode, the outlines a click on nothing shows go at once, rather than fading.
- Template cards don’t lift under the pointer; their shadow shows instead.

Changes of colour and opacity still fade, because they don’t move anything.

## Reduce Transparency

With **Reduce Transparency** on, the floating tool palette, the play bar and the sketch bar are drawn solid, with an edge, instead of on glass.

## Increase Contrast

With **Increase Contrast** on, the Welcome window and the template gallery give template cards, recent documents and category rows stronger edges, and their captions and counts darker ink. A sheet’s main button gets an edge of its own.
