What do I need to run FlectoBI?

A Mac with Apple silicon, running macOS 26 or later. FlectoBI does not run on Intel Macs, and there is no version for iPhone or iPad yet. FlectoBI is coming to the Mac App Store.

Where is the sample Workbook?

Choose Help, then Open Sample Workbook. You can also click Open Sample Workbook on an empty Flow. FlectoBI copies the sample into a folder called FlectoBI Samples in its own Documents folder and opens Sales Sample. It has a Flow of twelve Steps and a Report with five Pages, and it needs no permission to read its files.

If you change the sample, FlectoBI keeps your Workbook and only refreshes its data files.

FlectoBI says it needs permission to read a file. What do I do?

FlectoBI is a sandboxed Mac app, so it can open only the files you choose. When you pick or drop a file, FlectoBI keeps a bookmark so it can open that file again later without asking. A Workbook from another Mac, or a folder that has moved, has no such bookmark yet. An orange banner then appears at the top of the window, for example “FlectoBI needs permission to read 3 input files.”

  1. Click Grant Access… in the banner.
  2. Choose the folder that holds the Workbook’s data, or the files themselves. The panel starts at the folder they have in common.
  3. Click Grant Access. The Steps read their files again by themselves.

One grant for a folder covers everything inside it, so choosing the common folder usually fixes every Step at once. You can see and remove each grant in Settings, under Access. Removing a grant takes effect at once, and data FlectoBI has already read stays in open Workbooks until you refresh them.

If a file is missing, FlectoBI says so instead: “It may have been moved, renamed or deleted, or be on a drive that isn’t connected.” Granting access cannot bring a missing file back. Use Change File… in the Input’s options to point to it.

For an SQLite database, FlectoBI may need the whole folder, because SQLite keeps working files next to the database. The banner then says “FlectoBI needs access to the folder of” the file.

FlectoBI refused my Excel file. Why?

FlectoBI reads .xlsx, .xlsm, .xlsb, .xls and .ods files in a separate, sandboxed helper, so a damaged file cannot crash the app. The helper refuses a file it cannot read safely, and the message says what to do:

  • “The workbook is password-protected or encrypted. Remove the password in Excel and try again.”
  • “The sheet is too large to import. Save it as CSV and import that instead.” A sheet may have at most 50,000,000 cells, and .xls and .ods sheets at most 20,000,000.
  • FlectoBI says it stopped reading the file because the file made the spreadsheet reader fail. The file may be damaged. Try opening and saving it in Excel, or save it as CSV.
  • “The file is damaged or not a valid spreadsheet.”
  • “The sheet is empty.” or “The workbook has no sheets.”

Saving the sheet as CSV or Parquet from Excel works around all of these. If the file has more than one sheet, choose the one you want in the Input’s options. FlectoBI reads the first visible sheet by default, and the Range option reads only the cells you name, such as A1:F200. A file may be at most 1 GiB, and an .xls or .ods file at most 200 MiB.

My CSV file reads wrongly

  • Dates read the wrong way round. A date such as 03/04/2025 can mean two days. Set Date order in the Input’s options to Month first or Day first.
  • Numbers such as 1.234,56. Set Decimals to Comma, or use a Change Type Step with Numbers use a decimal comma turned on.
  • Leading zeros are gone. Turn on Read every column as text, then use Change Type where you want numbers.
  • Strange characters. Choose the file’s Encoding instead of Automatic. When it cannot tell, FlectoBI says that the file is not UTF-8 text and asks you to choose its encoding in the Input’s options.
  • A title above the header. Raise Skip rows until the header is the first row read.

A database connection fails. What do the messages mean?

FlectoBI connects to PostgreSQL, MySQL and MariaDB servers, and only reads from them. Use Test Connection in the sheet to see the result before you add the Input. The messages say what to change:

MessageWhat to do
Authentication failed. Check the user name and password.Re-enter the user and password. The password is stored in your Mac’s Keychain, not in the Workbook.
The server refused the connection. Check the host and port.The defaults are 5432 for PostgreSQL and 3306 for MySQL. Check that the server accepts connections from your network.
The host name could not be found.Check the spelling, and check that you are on the right network or VPN.
The server did not respond in time.Check the host and port, and any firewall in between.
The server does not allow connections from this Mac.Ask the administrator to allow your Mac’s address.
The server requires SSL. Choose Require or Verify certificate.Change the SSL setting in the sheet.
The server does not support SSL. Try a different SSL mode.Choose Prefer, or Off for a server on your own Mac.
The server’s certificate could not be verified. If the server uses its own certificate, choose Require.Verify certificate checks the certificate against the ones your Mac trusts. If your server uses a certificate it made itself, choose Require.
The server offers only an outdated encryption version (TLS 1.0 or 1.1). Ask the administrator to turn on TLS 1.2 or later.FlectoBI needs TLS 1.2 or later for MySQL.
The server asked for the password in a form that could be intercepted, so it was not sent. Choose Verify certificate, or set up the server for SCRAM passwords.FlectoBI never sends a PostgreSQL password in clear text or as MD5. Ask for SCRAM passwords on the server.
This account signs in with a method FlectoBI does not support.Ask for an account with a caching_sha2_password or mysql_native_password password.

The SSL setting has four choices: Off, Prefer, Require and Verify certificate. For a server on another machine, a new connection starts at Require for PostgreSQL and Verify certificate for MySQL. Choose Off only for a server on your own Mac, or one that offers no encryption, and know that the password and the data can then be read on the network.

A custom query for MySQL must read data. Start it with SELECT, WITH, TABLE or VALUES, and enter one query only. FlectoBI does not write to any database.

MySQL 8.4, 9.7 and 26.x and MariaDB 11.8 are tested. Accounts that sign in with ed25519, PARSEC or sha256_password are not supported.

A Step stops because of memory or disk. What can I do?

FlectoBI keeps its data engine to about 30% of your Mac’s memory and writes the overflow to temporary disk space. A Step stops when the whole app passes 80% of the memory, and says that it needs more memory than is available, and that you should filter or summarize the data earlier in the Flow, or simplify the Formula.

  • Put a Filter or Keep/Remove Columns Step as early in the Flow as you can, so later Steps handle less.
  • Summarize before you Join or Pivot.
  • Close other Workbooks, which each have their own engine.
  • Free some disk space. The space for overflow is limited to a quarter of what is free.
  • Press Command-period to stop a Step that is running.

An Output will not write

  • It would overwrite an Input. FlectoBI says that the Output would overwrite a file the Flow reads, and asks you to choose another file. FlectoBI never writes over a source file.
  • It needs permission. Use Grant Access in the banner, or Change… to choose the file again.
  • Excel is limited. Excel files are written as .xlsx, with at most 1,048,575 rows. For more, write CSV or Parquet.
  • Nothing happens when the Workbook opens. This is on purpose. An Output writes when you click Write Now, or choose Write All Outputs, and automatic writing starts only after that.

A write goes to a temporary file first, and replaces the destination only when it is complete. If it fails, “The file was left as it was.”

Do maps need the internet?

No. The shapes of countries, states and regions, and the names of cities of 15,000 people or more, come with the app. FlectoBI does not call a map service.

If a place is not found, the Visual lists it, and suggests that you check the spelling or add a Country field, so FlectoBI can tell places with the same name apart. Where a name could be several places, FlectoBI uses the largest and says so. Postal codes are not supported.

How do I share a Workbook?

Send the .flectobi file together with its data files, and keep the folders as they were: the Workbook stores paths relative to itself. A Workbook holds the recipe, never the data and never a password.

On the other Mac, FlectoBI shows the Grant Access banner described above. One grant of the common folder fixes every Step. A database password does not travel: the person you share with is asked for it once, and it is saved in their own Keychain.

What are the limits in this version?

  • Inputs: files and PostgreSQL, MySQL and MariaDB databases. There is no Google Sheets, cloud storage or other database yet.
  • Transpose takes at most 1,000 rows, and Pivot at most 500 distinct values.
  • A Formula can be 4,000 characters long.
  • A chart shows up to 1,000 categories, a Table up to 1,000 rows, and a Scatter up to 20,000 points. A Visual says when it has cut the data.
  • Sharing is by file. There is no cloud and no shared editing.

Where are the acknowledgements?

Choose Help, then Acknowledgements, to see the notices for the open-source libraries inside FlectoBI. They include DuckDB for the data engine, and Natural Earth and GeoNames for the maps.
